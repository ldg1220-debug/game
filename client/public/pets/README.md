# 펫 스프라이트 이미지

이 폴더에 `{id}.png`를 넣으면 그 종은 코드 렌더링 대신 이미지로 표시됩니다.
파일이 없는 종은 기존 절차적 렌더러로 자동 대체되므로, **한 장씩 넣어가며**
교체할 수 있습니다. 코드는 손댈 필요 없습니다.

## 넣는 법

1. `prompts.md`(또는 `prompts.json`)에서 해당 종의 `fullPrompt`를 복사
2. 이미지 생성기에 넣고 생성
3. 결과를 이 폴더에 `{id}.png`로 저장 — 예: 3번 푸른뿔공룡 → `3.png`
4. 커밋

## 규격

- 파일명 `1.png` ~ `42.png` (펫 id)
- 권장 256×256 PNG
- 배경은 투명 또는 흰색 (게임 패널이 어두워서 투명이 더 잘 어울립니다)
- 픽셀 아트는 `image-rendering: pixelated`로 확대되므로 원본이 작아도 됩니다

## 확인

`/artlab`을 열면 42종을 한 화면에서 볼 수 있습니다. 이미지가 들어간 종은
이미지로, 아닌 종은 코드 렌더링으로 나옵니다.
