## 1. 게임 개요

### 1.1 게임 개념

**게임명**: 스톤에이지 유사 게임 (가칭: Stone Age Chronicles)

**장르**: 턴제 RPG, 펫 수집 및 육성 게임

**플랫폼**: 웹 기반 (React + TypeScript)

**핵심 컨셉**: 스톤에이지의 신비로운 세계관과 펫 포획 시스템을 현대적으로 재해석하면서, 믹스마스터의 확장성과 전략적 깊이를 결합한 게임.

### 1.2 게임의 주요 특징

- **광활한 탐험**: 여러 지역으로 이루어진 월드맵에서 자유로운 탐험.
- **전략적 전투**: 턴제 기반의 전략적인 전투 시스템.
- **펫 수집 및 육성**: 다양한 형상과 속성의 펫을 포획하고 육성.
- **성장률 기반 개체차**: 같은 종의 펫이라도 성장률에 따라 능력치가 크게 달라짐.
- **PvP 경쟁**: 다른 플레이어와의 경쟁을 통한 지속적인 게임 동기 부여.

### 1.3 플레이어 역할

플레이어는 **테이머(Tamer)**로서 펫을 포획하고 육성하며, 함께 전투를 벌이는 역할을 수행합니다. 테이머는 펫과의 유대 관계를 통해 더욱 강력한 팀을 구성할 수 있습니다.

## 2. 맵 구성 및 탐험 시스템

### 2.1 월드맵 구조

**대륙**: 원시 대륙 (가칭)

**지역 구성** (초기 5개 지역):

| 지역명 | 배경 | 권장 레벨 | 출현 펫 특징 | 주요 던전 |
|--------|------|---------|-----------|---------|
| 푸른 초원 | 넓은 초원, 밝은 햇빛 | 1~20 | 귀여운 형상, 다양한 속성 | 초원의 동굴 |
| 울창한 숲 | 우거진 나무, 신비로운 분위기 | 15~35 | 강한 형상, 자연 속성 | 숲의 심장 |
| 험준한 산맥 | 높은 산, 거친 지형 | 30~50 | 강직한 형상, 지 속성 | 산맥의 봉우리 |
| 불타는 화산 | 용암, 뜨거운 열기 | 45~65 | 강한 형상, 화 속성 | 화산의 심장부 |
| 신비한 빙산 | 얼음, 차가운 바람 | 60~80 | 강직한 형상, 수 속성 | 빙산의 궁전 |

### 2.2 지역별 구성 요소

**마을 (Town)**:
- NPC (상점, 펫 관리사, 퀘스트 제공자)
- 펫 보관소 (박스)
- 회복 시설 (포션 판매)
- 거래소 (추후 구현)

**필드 (Field)**:
- 야생 펫 출현
- 자유로운 이동
- 숨겨진 요소 (보물 상자, 히든 퀘스트)

**던전 (Dungeon)**:
- 일반 필드보다 강력한 펫 출현
- 희귀 아이템 및 재료 획득
- 보스 펫 (특정 던전)
- 특정 퀘스트 진행에 필요

### 2.3 탐험 메커니즘

- **필드 이동**: 플레이어 캐릭터가 맵 위를 직접 이동.
- **야생 펫 조우**: 필드에서 일정 확률로 야생 펫과 조우.
- **전투 진입**: 조우 시 별도의 전투 화면으로 전환.
- **워프 포인트**: 마을 간, 또는 특정 지역 간 빠른 이동.

## 3. 펫 시스템

### 3.1 펫의 구성 요소

**펫 개체 = 종(Species) + 성장률(Growth Rate) + 성향(Nature) + 개성(Personality)**

### 3.2 펫 종(Species)

**형상(Shape)**: 40~50가지의 독특한 펫 형상.

**속성(Element)**: 5가지 기본 속성 (화, 수, 지, 풍, 무)

**기본 펫 종**: 40~50 형상 × 5 속성 = 200~250종

**같은 형상의 속성 조합**: 각 형상마다 최대 5가지 속성 조합이 가능하며, 개체마다 다르게 구성됨.

### 3.3 성향(Nature) 시스템

**6가지 성향** (각 16.67% 확률):

| 성향 | 강화 | 약화 | 플레이 스타일 |
|------|------|------|-------------|
| 용감한 | STR +1 | AGI -1 | 공격형 |
| 민첩한 | AGI +1 | STR -1 | 속도형 |
| 튼튼한 | VIT +1 | SPA -1 | 방어형 |
| 똑똑한 | SPA +1 | VIT -1 | 특수형 |
| 신중한 | SPD +1 | AGI -1 | 특방형 |
| 균형잡힌 | 없음 | 없음 | 올라운더 |

### 3.4 개성(Personality) 시스템

**6가지 개성** (각 16.67% 확률):

| 개성 | 효과 | 설명 |
|------|------|------|
| 크리티컬 | LCK +2 | 높은 크리티컬 확률 |
| 회피 | AGI +1 | 높은 회피율 |
| 경험치 | - | 경험치 +10% |
| 운 | LCK +3 | 매우 높은 크리티컬 |
| 회복 | VIT +1 | 높은 체력 |
| 일반 | 없음 | 특수 효과 없음 |

### 3.5 펫 포획 시스템

**포획 프로세스**:

1. 야생 펫과 조우
2. 전투 또는 포획 선택
3. 포획 시도 (포켓볼 사용)
4. 포획 성공 (테이밍 펫)
5. 개체 생성 (성장률, 성향, 개성 결정)
6. 팀에 추가 또는 박스에 저장

**포획 확률**:
- 포켓볼 종류별 배수 (1.0~4.0)
- 펫 상태 배수 (정상 1.0 ~ 동결/수면 1.5)
- 플레이어 레벨 보정
- 포획 실패 시 전투 또는 도망치기 선택

**테이밍 펫 출현**:
- 야생 펫 중 2~10% 확률로 Lv.1 테이밍 펫 출현
- 포획 후 팀에 추가하거나 박스에 저장

## 4. 성장률 시스템

### 4.1 성장률의 정의

**성장률(Growth Rate)**: 펫이 레벨업할 때마다 상승하는 능력치의 배수.

**범위**: 0.85배 ~ 1.15배 (일반 개체), 1.20배 이상 (서버 전설 개체)

**평균**: 1.00배

### 4.2 성장률 분포 (피라미드식)

**일반 개체 (99%)**:

| 구간 | 확률 | 성장률 범위 | 평가 |
|------|------|-----------|------|
| 최상위급 | 1% | 1.10~1.15배 | +10~15% |
| 상위급 | 5% | 1.05~1.09배 | +5~9% |
| 중상급 | 15% | 1.00~1.04배 | 0~4% |
| 중급 | 30% | 0.95~0.99배 | -1~5% |
| 하위급 | 35% | 0.90~0.94배 | -6~10% |
| 최하위급 | 14% | 0.85~0.89배 | -11~15% |

**서버 전설 개체 (0.0000044% = 3개월에 1개)**:

| 구간 | 확률 | 성장률 범위 | 평가 |
|------|------|-----------|------|
| 서버 전설 | 0.0000044% | 1.20배 이상 | +20% 이상 |

### 4.3 개별 능력치별 성장률

각 능력치(STR, AGI, VIT, SPA, SPD, LCK)마다 독립적인 성장률 존재:

```
STR 성장률: 0.85 ~ 1.15배
AGI 성장률: 0.85 ~ 1.15배
VIT 성장률: 0.85 ~ 1.15배
SPA 성장률: 0.85 ~ 1.15배
SPD 성장률: 0.85 ~ 1.15배
LCK 성장률: 0.85 ~ 1.15배
```

### 4.4 0레벨 개념

**0레벨**: 펫이 포획되었을 때의 초기 상태 (Lv.1 직전)

```
0레벨 능력치 = 기본 Stat × 성장률

예시:
- 기본 STR: 8
- STR 성장률: 1.12배
- 0레벨 STR: 8 × 1.12 = 8.96 ≈ 9
```

### 4.5 레벨별 능력치 계산

```
Lv.N 능력치 = 0레벨 능력치 + (성장률 × (N - 1))

예시 (STR):
- 0레벨 STR: 9
- STR 성장률: 1.12배
- Lv.1 STR: 9
- Lv.2 STR: 9 + 1.12 = 10.12 ≈ 10
- Lv.100 STR: 9 + (1.12 × 99) = 9 + 110.88 = 119.88 ≈ 120
```

### 4.6 Stat에서 게임 능력치로의 변환

```
HP = VIT × 5 + 10
공격력 = STR × 2 + 5
방어력 = (VIT + SPD) / 2 + 3
특공 = SPA × 2 + 5
특방 = SPD × 2 + 5
속도 = AGI × 2 + 1
크리티컬 = LCK × 1 + 3 (%)
```

## 5. 전투 시스템

### 5.1 기본 전투 방식

**턴제 전투 (Turn-Based Combat)**

- **전투 진입**: 필드에서 야생 펫과 조우 시 별도의 전투 화면으로 전환.
- **펫 팀 구성**: 최대 5마리의 펫으로 팀을 구성.
- **행동 순서**: 펫의 '속도' 능력치와 '우선도'에 따라 행동 순서 결정.

### 5.2 스킬 시스템

**펫의 행동 옵션**:

- **일반 공격**: 기본 데미지 (STR 기반).
- **액티브 스킬**: 속성 공격, 상태 이상, 버프/디버프 등 다양한 효과.
- **방어**: 받는 데미지 감소.
- **교체**: 전투 중 다른 펫으로 교체.

### 5.3 속성 상성 시스템

**상성 매트릭스**:

| 공격 속성 | 유리 | 불리 | 중립 |
|----------|------|------|------|
| 화 | 지 | 수, 풍 | 화, 무 |
| 수 | 화, 풍 | 지 | 수, 무 |
| 지 | 수 | 화, 풍 | 지, 무 |
| 풍 | 화, 지 | 수 | 풍, 무 |
| 무 | 없음 | 없음 | 모두 |

**상성 배수**:
- 유리 상성: 2.0배
- 중립 상성: 1.0배
- 불리 상성: 0.5배

**이중 속성 상성 계산**:

```
상성 배수 = (주속성 상성 배수 × 주속성 비율) + (부속성 상성 배수 × 부속성 비율)

예시:
공격자: 화9 + 수1
방어자: 지10

화 vs 지 상성: 2.0배
수 vs 지 상성: 0.5배

상성 배수 = (2.0 × 0.9) + (0.5 × 0.1) = 1.8 + 0.05 = 1.85배
```

### 5.4 데미지 계산

```
기본 데미지 = 공격자 공격력 × 스킬 위력 / 방어자 방어력

최종 데미지 = 기본 데미지 × 상성 배수 × 크리티컬 배수

크리티컬 배수 = 1.0 (일반) 또는 1.5 (크리티컬)
```

### 5.5 전투 승패 조건

- **승리**: 상대 팀의 모든 펫을 쓰러뜨림.
- **패배**: 자신의 모든 펫이 쓰러짐 (마을로 귀환, 패널티 부여).

### 5.6 PvP 시스템

- **아레나**: 다른 플레이어의 펫 팀과 대결.
- **랭킹 시스템**: PvP 승패에 따라 랭킹 부여.
- **시즌 보상**: 시즌별 랭킹에 따른 보상 제공.

## 6. 경제 및 아이템 시스템

### 6.1 화폐 시스템

**금전 (Gold)**:
- 야생 펫 사냥으로 획득
- PvP 승리로 획득
- 퀘스트 완료로 획득

**사용처**:
- 포켓볼 구매
- 회복 포션 구매
- 아이템 구매

### 6.2 아이템 시스템

**포켓볼**:
- 일반 포켓볼 (1.0배 포획률)
- 좋은 포켓볼 (1.5배 포획률)
- 슈퍼 포켓볼 (2.0배 포획률)
- 마스터볼 (4.0배 포획률, 희귀)

**회복 아이템**:
- 포션 (HP 회복)
- 전회복 포션 (전체 HP 회복)
- 상태 이상 치료제

**재료 아이템**:
- 진화 재료
- 강화 재료
- 합성 재료 (추후)

### 6.3 경제 순환

```
포획 → 전투 → 보상 (금전) → 포켓볼 구매 → 계속 포획
```

## 7. UI/UX 설계

### 7.1 주요 화면

**메인 화면**:
- 플레이어 정보 (레벨, 경험치, 금전)
- 팀 구성 (현재 펫 팀)
- 네비게이션 (탐험, 펫 관리, 포켓덱스, PvP, 설정)

**탐험 화면**:
- 월드맵 (현재 위치, 이동 가능 지역)
- 필드 (펫 출현, 상호작용 가능 요소)
- 마을 (NPC, 상점, 펫 보관소)

**펫 관리 화면**:
- 팀 편성 (펫 선택, 순서 변경)
- 펫 정보 (능력치, 성향, 개성, 성장률)
- 펫 육성 (레벨업, 경험치 표시)

**전투 화면**:
- 펫 상태 (HP바, 상태 이상)
- 행동 선택 (공격, 방어, 교체, 도망)
- 전투 로그 (데미지, 상태 변화)

**포켓덱스 화면**:
- 포획한 펫 목록 (형상, 속성, 개수)
- 포획 통계 (총 포획 수, 도감 완성도)

**PvP 화면**:
- 아레나 (상대 선택, 전투)
- 랭킹 (플레이어 순위, 보상)

### 7.2 UI 디자인 원칙

- **신비로운 정령의 세계**: 진한 남색/보라색 배경, 금색 강조색.
- **Cinzel + Poppins**: 제목은 Cinzel, 본문은 Poppins 폰트 사용.
- **입자 이펙트**: 신비한 분위기를 위한 입자 이펙트 활용.
- **속성별 색상**: 각 속성별로 고유한 색상 사용 (화=빨강, 수=파랑, 지=초록, 풍=노랑, 무=회색).

## 8. 개발 로드맵

### 8.1 Phase 1 (MVP, 4주)

**주 목표**: 기본 게임 루프 완성

**구현 항목**:
1. 맵 이동 및 필드 시스템
2. 야생 펫 조우 및 전투
3. 성장률 기반 펫 포획
4. 펫 팀 관리 및 편성
5. 기본 UI/UX
6. 1개 지역, 1개 마을, 1개 던전

**예상 완료**: 4주

### 8.2 Phase 2 (콘텐츠 확장, 6주)

**주 목표**: 콘텐츠 다양화 및 게임 깊이 증가

**구현 항목**:
1. 맵 확장 (2~3개 지역 추가)
2. 스킬 시스템 심화

## 10. 마무리

이 문서는 스톤에이지 유사 게임의 완전한 개발 가이드입니다. Claude는 이 문서를 기반으로 일관성 있고 효율적인 개발을 진행할 수 있습니다. 각 Phase별로 명확한 목표와 구현 항목이 정의되어 있으므로, 단계적으로 게임을 완성할 수 있을 것입니다.

**주요 참고사항**:
- 모든 능력치는 정수(1의 단위)로 계산합니다.
- 성장률은 개체별로 독립적으로 결정되어 개체차를 극대화합니다.
- 속성 상성은 이중 속성을 고려한 가중치 기반 계산을 사용합니다.
- 펫 종은 형상과 속성 조합으로 생성되어 대규모 펫 풀을 구성합니다.
- 게임의 주 콘텐츠는 높은 성장률 펫 포획, PvP, 레벨업입니다.
