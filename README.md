# Stone Age Chronicles

스톤에이지에서 영감을 받은 웹 기반 펫 포획·육성 턴제 RPG.
같은 종의 펫이라도 **개체별 성장률**에 따라 최종 능력치가 크게 달라지며,
조금이라도 성장률이 높은 개체를 찾아 포획하고 육성하는 것이 핵심 재미입니다.

## 실행

```bash
cd client
npm install
npm run dev      # http://localhost:5173
npm run build    # 타입체크 + 프로덕션 빌드
```

## 현재 구현 범위 (Phase 1 / MVP)

- **탐험**: 마을 · 필드 · 던전 3개 지점, 야생 펫 랜덤 조우
- **전투**: 턴제, 속도/우선도 기반 행동 순서, 속성 상성, 크리티컬, 방어/교체/도망
- **포획**: 포켓볼 4종, 대상 HP·희귀도·레벨차 기반 포획률
- **성장률**: 6개 스탯 각각 독립 성장률(0.85~1.15배), 피라미드형 등급 분포, 전설 개체
- **육성**: 경험치·레벨업, 팀(최대 5)/보관함, 포션 회복
- **도감**: 포획 종 기록 및 완성도
- **PvP**: AI 팀과의 아레나 매치, 랭킹 점수
- **저장**: localStorage 자동 저장

## 설계 문서와 다르게 구현한 부분

기획 문서를 그대로 구현했을 때 플레이가 성립하지 않아 조정한 항목입니다.

### 1. 데미지 공식에 레벨 스케일링 추가

문서 5.4의 `기본 데미지 = 공격력 × 스킬 위력 / 방어자 방어력`을 그대로 쓰면
Lv.1 기준 한 번의 공격이 95 데미지가 나오는 반면 Lv.1 펫의 최대 HP는 35~65라
**선공권을 잡은 쪽이 무조건 1턴에 이기는** 상태가 됩니다.

레벨 항과 정규화 상수를 넣어 전 레벨 구간에서 6~8턴이 유지되도록 했습니다.

```
기본 데미지 = (레벨계수 × 위력 × 공격력 / 방어력) / 50 + 2
레벨계수  = 2 × 공격자레벨 / 5 + 2
```

상성 배수와 크리티컬 배수를 곱하는 최종 계산은 문서 그대로입니다.

### 2. 스타터 3종 기본 스탯 조정 및 성장률 하한

`HP = VIT × 5 + 10` 구조상 VIT가 다른 스탯보다 훨씬 무겁게 작용해,
기본 스탯 총합이 같아도 VIT가 낮은 종은 실전에서 크게 밀립니다.
스타터 3종의 VIT를 7~8 구간으로 맞췄습니다.

또한 첫 파트너는 평균 성장률 0.98 이상인 개체만 제시합니다(`generateStarterPet`).
전체 분포 평균이 0.953이라 하한을 두지 않으면 최하위급 스타터로 시작해
초반이 막힐 수 있습니다.

### 3. 초반 조우 보정

플레이어 레벨 5 미만 구간에서는 필드에 common 등급만, 플레이어 레벨 이하로만
출현시킵니다. 보정 전에는 Lv.1 스타터가 첫 야생 전투에서 승률 17~59%였습니다.

## 알려진 미해결 이슈

### 속성 상성표가 균형 사이클이 아님

문서 5.3의 상성표를 그대로 구현하면 속성 간 강약이 대칭이 아니라 **계층**이 됩니다.

| 속성 | 공격 유리 | 공격 불리 | 방어 약점 | 방어 저항 | 종합 |
|------|----------|----------|----------|----------|------|
| 수 | 화, 풍 | 지 | 지 | 화, 풍 | **+2** |
| 풍 | 화, 지 | 수 | 수 | 화, 지 | **+2** |
| 화 | 지 | 수, 풍 | 수, 풍 | 지 | **-2** |
| 지 | 수 | 화, 풍 | 화, 풍 | 수 | **-2** |

화 속성은 수·풍 양쪽에 2배로 맞으면서 유리한 상대는 지 하나뿐입니다.
이 때문에 불꽃여우 스타터는 스탯을 맞춘 뒤에도 첫 전투 승률이 33%에 머뭅니다
(솜털토끼 64%, 물방울슬라임 67%).

문서에 명시된 사양이라 **임의로 바꾸지 않고 그대로 두었습니다.** 균형 잡힌
4속성 사이클(화 > 풍 > 지 > 수 > 화)로 바꿀지는 별도 결정이 필요합니다.
